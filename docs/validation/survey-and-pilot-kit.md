# User validation kit (P-07, B-07)

Run by the 3-person team in about 1–2 weeks. Get a DIU supervisor's sign-off first. No names or phone numbers in the dataset.

## 1. Consent (read aloud in Bangla, tick on the form)

> আমরা DIU-এর শিক্ষার্থী, একটি গবেষণার জন্য টাকা-পয়সা নিয়ে কয়েকটি প্রশ্ন করছি। আপনার নাম বা ফোন নম্বর রাখা হবে না। যেকোনো প্রশ্নের উত্তর না দিতে পারেন, যেকোনো সময় থামতে পারেন, পরে বললে আপনার উত্তর মুছে ফেলা হবে। এটা কোনো ঋণ বা আর্থিক পরামর্শ নয়।

## 2. Survey (Google Form in Bangla, filled face to face) — target n ≥ 60

1. Occupation (garment worker / daily wage / shopkeeper / student / other)
2. Which MFS do you use? How is your income paid (cash / MFS / bank)?
3. In the last 3 months, how many times did money run out before the next income? (0 / 1 / 2 / 3+)
4. Around which day of the month does it usually start to run short?
5. What did you do then? (borrow family/friends, shop credit, NGO/loan, skip meals, sell something, other)
6. On your last payday, how much did you cash out, and what fee did you pay?
7. If your phone warned you about 5 days before money runs short, how useful would that be? (1–5)
8. Which of these would you actually do? (set money aside on payday, daily spending limit, send home by NPSB, pay shops from the wallet)
9. Would you trust such a warning inside the upay app? (1–5)

## 3. Diary study — n = 8–10, 5–7 days

Daily WhatsApp voice note: balance today, money in, money out, "short today?" yes/no. ৳50/day mobile recharge as thanks (not tied to answers).

## 4. Usability test — n = 8–10

Show the prototype's Forecast page. Tasks: "When will you run short?", "Why?", "What would you do?". Record task success, time, and SUS (10 questions).

## 5. Pilot (B-07) — 30–40 participants, 2 weeks

- Randomise 1:1 in blocks by occupation. Week 1: everyone logs money in/out. Week 2: treatment sees forecasts and action cards, control only logs.
- Pre-register before day 1 (AsPredicted or OSF): H1 acceptance ≥ 30% (Wilson 95% lower bound); H2 forecast beats "same as last week"; H3 fewer short/borrow days in treatment (permutation difference-in-differences); H4 SUS ≥ 68.
- Report all results, including nulls. Present it as feasibility and acceptance evidence, not proof of impact.

## 6. Results template (for the report and one slide)

- "X% of N ran short in the last 3 months (median start day Y)."
- "Z% borrowed informally the last time."
- "W% rated a 5-day warning ≥ 4/5."
- 2–3 anonymised quotes, a diary heatmap (day of month × participant), and the sampling limits.
